# 音量与播放模式修复说明

已让 QQ 音乐和网易云音乐使用游戏原有的音量与播放模式控制：

- 底部音量滑块可即时调整音量，支持静音，切歌后保持所选音量。
- 列表循环会在队列末尾返回第一首，只有一首时也会重播。
- 单曲循环在自然播放结束后从本地缓存重播；手动上一首、下一首照常切歌。
- 随机播放使用打乱后的队列，轮次交界避免立即重复，上一首按本轮实际播放顺序返回。
- 播放队列增删、插入歌单或调整顺序后，随机播放会按更新后的队列重新安排。

本机下次从 Steam 启动即可生效；使用已打开的游戏时，先正常退出再启动。

验证：31 项播放控制检查、30 项既有队列/音源切换回归检查均通过。补丁成功编译，并从实际生成的游戏文件反编译后再次通过 31 项控制检查。实际听感及游戏内交互还需在正常游玩中确认。
