# 音源切换与歌单自动加载

- 点击 QQ 音乐或网易云音乐标签后直接显示并加载该音源的歌单，不再需要额外点击“歌单”。
- 请求繁忙时保留歌单加载任务，通道空闲后自动补发；播放请求仍优先于歌单和后台预取。
- 切换音源后丢弃旧页面的迟到回复，避免旧歌单、旧搜索结果或旧连接错误覆盖当前页面。
- 正确忽略 HTTP 接收进度回调，不再把“正在接收数据”当作断线。真实断线时提示当前音源名称，成功重试后清除错误。
- 网易云歌单不再依赖 QQ 登录状态；登录提示取自当前音源的歌单回复。

已验证：15 项音源切换/异步检查、15 项原有面板/队列检查、3 项桥接音源隔离检查。编译后的游戏数据已重新读取并验证；模拟 QQ 未登录时，真实网易云账号仍能加载 46 个歌单。

GameMaker 的 `status=1` 表示接收中、`status=0` 表示完成，负数才表示请求错误，参见 [官方 HTTP 文档](https://manual.gamemaker.io/lts/en/GameMaker_Language/GML_Reference/Asynchronous_Functions/HTTP/http_get.htm)。

本次会备份并同步桥接文件、游戏补丁、重装模板和校验值，不修改登录信息、存档或播放缓存。
