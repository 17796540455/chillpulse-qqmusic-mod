# ChillPulse 音乐 Mod

在 ChillPulse 的音乐面板中使用 **QQ 音乐、网易云音乐和本地音乐**。支持搜索歌曲、读取自己的歌单，以及调整播放队列。

**安装一次，以后直接从 Steam 游戏库启动。** 后台音乐服务随游戏自动启动和退出，无需另开命令行窗口。

## 安装前准备

- Windows 10 / 11，64 位；已通过 Steam 安装 ChillPulse。
- [Python 3.9 或更高版本](https://www.python.org/downloads/windows/)。安装时保留默认的 **tcl/tk and IDLE** 组件。
- ffmpeg。安装程序会检查，缺少时可按提示通过 winget 安装；也可自行安装并加入 PATH。
- 关闭正在运行的 ChillPulse，等待 Steam 恢复“开始游戏”按钮。

首次安装需要联网下载补丁工具，可能需要几分钟。Mod 不包含游戏文件，请在自己的游戏安装上使用。

## 首次安装

1. 在本仓库选择 **Code → Download ZIP**，解压到一个准备长期保留、可写的目录，例如 `D:\ChillPulseMusicMod`。不要直接在压缩包里运行。
2. 双击 **`install.bat`**。它会查找游戏、检查环境、备份原文件并安装 Mod；找不到游戏时，粘贴 Steam → ChillPulse → 管理 → 浏览本地文件所打开的目录。
3. 安装完成时，**Steam 启动参数会复制到剪贴板**。打开 Steam → ChillPulse → **属性 → 通用 → 启动选项**，粘贴整行。原先有游戏参数时，将它们保留在 `%command%` 后面。
4. 在自动打开的账号设置窗口中，设置你要用的音乐平台，方法见下文。两个平台可以分别设置，也可以只用其中一个。
5. 从 **Steam 游戏库**启动 ChillPulse，打开音乐面板，点击 **QQ 音乐**或**网易云音乐**。歌单会自动加载。

第三步只需要做一次，无需完全退出 Steam。日后要重新复制参数，双击 **`复制Steam启动参数.bat`**；剪贴板不可用时，可打开 `runtime\steam_launch_options.txt`，复制其中整行。

**请保留解压后的整个目录。** 移动或删除它会让 Steam 找不到启动器；移动后需重新运行安装并更新启动参数。

## QQ 音乐与网易云如何登录

双击 **`账号设置.bat`**，选择对应平台。每个平台都有“打开官网登录”“验证并保存”“检查已保存登录”和“退出 Mod 登录”。

目前稳定的方式是：**在官方网页登录，再把网页的 Cookie 导入 Mod 一次**。只登录手机或桌面客户端，Mod 不会自动获得登录状态。当前尚未提供 Mod 内直接扫码登录。

### QQ 音乐

1. 在设置窗口选择 **QQ 音乐 → 打开官网登录**，打开 [QQ 音乐官网](https://y.qq.com/)。在官网按提示扫码或使用其支持的方式登录。
2. 登录后，按 **F12** 打开浏览器开发者工具，切到 **网络 / Network**，刷新网页。
3. 选择一个发往 `y.qq.com` 或 `u.y.qq.com`、带 Cookie 的请求，展开 **标头 / Headers → 请求标头 / Request Headers**。
4. 复制 **Cookie 的整项值**，不要复制整个请求、响应标头或 `Set-Cookie`。通常应包含 `uin`（或 `wxuin`）以及 `qm_keyst`（或 `qqmusic_key`）。
5. 回到账号设置，粘贴到输入框，点击 **验证并保存**。工具会检查格式、尝试读取歌单并保存，不需要手填 QQ 号或编辑文件。
6. 重新打开游戏，选择 QQ 音乐并播放一首歌，确认账号的播放权限。

### 网易云音乐

1. 在设置窗口选择 **网易云音乐 → 打开官网登录**，打开 [网易云音乐官网](https://music.163.com/)。在官网按提示扫码或使用其支持的方式登录。
2. 按 **F12 → 网络 / Network**，刷新网页。
3. 选择一个发往 `music.163.com`、带 Cookie 的请求，在 **标头 / Headers → 请求标头 / Request Headers** 中复制 **Cookie 的整项值**。其中应包含 `MUSIC_U`。
4. 回到账号设置，粘贴并点击 **验证并保存**。成功后会显示已验证的账号昵称。
5. 重新打开游戏，选择网易云音乐，等待自动加载歌单。

找不到 Cookie 时，确认网页右上角已显示自己的账号，再刷新或打开自己的歌单，换一个请求检查。不要使用 `document.cookie` 代替请求标头中的完整 Cookie，它可能漏掉登录信息。

登录信息只保存在本机的 Mod 运行目录中，验证时仅发送给对应音乐平台。**Cookie 相当于登录凭证，不要发给别人，也不要连同整个运行目录上传。** 失效后重新导入即可；“退出 Mod 登录”只移除本机 Mod 保存的信息。

QQ 音乐的歌单读取检查不代表所有歌曲都能播放。会员、付费专辑及地区限制仍以账号实际权限为准，Mod 不提供额外权限。

## 日常使用

1. 在 Steam 游戏库点击 **开始游戏**。
2. 打开游戏左下角的音乐面板，选择 QQ 音乐或网易云音乐，歌单会自动出现。
3. 选择歌单，再点击其中的歌曲开始播放；也可以搜索歌名或歌手并点击结果播放。

- **切换音源**：点击对应标签即可；选择“本地音乐”使用游戏原有的本地音乐功能，无需登录在线账号。
- **加入歌单**：播放另一歌单中的歌曲时，该歌单插到当前播放歌曲之后。
- **播放队列**：点歌曲跳播，使用 `▲` / `▼` 调整顺序，`×` 移除。
- **播放控制**：使用底部的暂停、上一首、下一首。
- **音量**：拖动底部音量滑块，可调整 QQ 音乐和网易云音乐的音量；暂停、切歌后仍保持所选音量。
- **播放模式**：点击底部模式按钮切换列表循环、单曲循环和随机播放。单曲循环只在歌曲自然结束时重播，手动上一首、下一首仍可切歌。
- **首次播放**：需要下载并处理音频，请等待加载完成；已缓存歌曲通常更快。
- **退出**：正常关闭游戏即可，后台服务会一同退出。

## 更新与卸载

**更新 Mod**：先关闭游戏，将新版文件解压覆盖到原来的 Mod 目录，再运行 `install.bat`。已有的 `runtime` 目录请保留，安装会保留其中的账号信息。检查 Steam 启动参数仍指向当前目录即可。

**Steam 验证游戏文件后**：如果游戏版本未变化，下次通过启动器启动会自动恢复 Mod。若提示版本不匹配，请等待适配该游戏版本的 Mod，不要用旧文件覆盖新版游戏。

**卸载**：关闭游戏，在 Steam 属性中移除本 Mod 的启动参数，再使用 Steam 的“验证游戏文件的完整性”恢复原版。之后可删除 Mod 目录；如有自己的其他启动参数，请保留。

## 常见问题

**提示未连接、没有 QQ／网易云标签**：先检查 Steam 启动选项是否已经粘贴完整，并确认 Mod 目录没有移动。不要另外运行旧版的后台启动脚本。

**提示未登录或歌单为空**：打开 `账号设置.bat`，检查对应平台的登录；过期时重新导入 Cookie。两个账号分别设置，QQ 未登录不影响网易云。

**显示会员／试听限制**：先在对应官网确认同一账号能否完整播放。若只能试听，需由账号本身获得完整播放权限。

**游戏更新后无法启动 Mod**：当前 Mod 会拒绝覆盖不匹配的游戏版本。可暂时移除 Steam 中的 Mod 启动参数并验证游戏文件，使用原版等待更新。

更多排查方法见[使用问题排查](docs/troubleshooting.md)。
