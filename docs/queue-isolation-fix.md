# 随机播放混入队列外歌曲的修复

在线切歌会先释放旧音频再等待新歌曲。旧补丁只在音频已经加载时阻止原版播放器，导致加载期间、播放失败后或解锁场景时，原版可能按自己的列表播放本地卡带。

现在在线队列在加载和报错期间继续持有播放控制，只有主动播放本地卡带或停止在线播放时才交还。连续切歌时，过期的播放与状态查询响应会被忽略；失败歌曲保留标题和队列位置，便于继续下一首。

验证：旧补丁已复现队列外卡带误播。新增 26 项检查（其中 14 项执行实际编译后反编译出的原版 Step 播放事件），以及 61 项既有音量、模式、队列和音源切换检查，均已通过。新补丁成功编译。

本机重启游戏后生效，实际随机播放表现仍需正常游玩确认。
